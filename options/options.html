Alianza OTP Pruebas — Opciones

Portal de origen

Portales donde se consulta el usuario para obtener el OTP.

Escriba una URL por línea. Se solicitará permiso para acceder a estos sitios.

Sitio OTP

Sitio donde se consultan los códigos OTP. Introduzca la URL y las credenciales de acceso.

Se solicitará permiso para acceder a este sitio.

La contraseña se guarda sin cifrar en chrome.storage.local.

Aplicar el código a un campo

El popup puede escribir el OTP en el portal. Indique el selector CSS del campo; déjelo vacío para ocultar el botón.

Debe apuntar a un input o textarea editable. Si coincide con varios campos de un dígito, el código se reparte entre ellos.

Refresco automático

Mientras el popup esté abierto, el código se actualiza automáticamente al caducar.

Normalmente son 60 segundos. Ajuste este valor si no coincide con el cambio del código.
