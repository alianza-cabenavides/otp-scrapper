Alianza OTP Pruebas — Opciones

Portal de origen

Sitio donde el operador trabaja y donde vive sessionStorage["userData"]. Se lee su identificationNumber para consultar el OTP.

Al guardar se te pedirá permiso para leer ese sitio.

Sitio OTP

Administrador de tokens donde se consultan los OTP. Introduce su URL base (ej. el sitio de pruebas o el de producción) y las credenciales de acceso.

Al guardar se te pedirá permiso para acceder a ese sitio.

⚠️ La contraseña se guarda en chrome.storage.local en texto plano (local a esta extensión).

Aplicar el código a un campo

El popup muestra un botón que escribe el código directamente en la pestaña del portal. Indica el selector CSS que identifica el campo; si lo dejas vacío, ese botón no aparece.

Se busca con document.querySelectorAll en la pestaña del portal y debe apuntar a input o textarea editables. Si coincide un solo campo recibe el código completo; si el portal usa un grupo de casillas de un dígito, haz que coincidan todas (por ejemplo input.token-digit) y se reparte una cifra en cada una.

Refresco automático

Mientras el popup está abierto se muestra una cuenta atrás con la vida restante del código; al agotarse se releen sólo los OTP, sin volver a consultar la tabla de dispositivos.

El proveedor confirma 60 segundos. Se deja configurable por si cambiara; si la cuenta atrás no coincide con el cambio real del código, ajústalo aquí.
